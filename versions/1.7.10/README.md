# Botas for Minecraft 1.7.10

This is the separate Legacy Fabric 1.7.10 port. See [installation](../../docs/INSTALL.md), [features and limitations](../../docs/FEATURES.md), and [build instructions](../../docs/DEVELOPMENT.md).

```sh
bash gradlew -p versions/1.7.10 build
bash gradlew -p versions/1.7.10 runClient
```

Use `@help` for this port's supported commands. It has resource gathering, crafting, navigation and partial progression experiments, but does not inherit the 1.8 assisted TAS route. Experimental TNT and save/reload duplication commands are non-speedrun features and are not confirmed successful duplication methods.
